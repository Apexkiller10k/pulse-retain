# Deployment Guide for PulseRetain

## Required Files for Streamlit Cloud

PulseRetain requires these runtime artifacts to function on Streamlit Cloud:

### Data

```
data/raw/HR-Employee-Attrition.csv
```

This is the IBM HR Analytics dataset used for predictions. The application will not load without it.

### Model Artifacts

```
models/attrition_model.pkl          # Trained XGBoost pipeline
models/preprocessor.pkl             # Feature preprocessing pipeline
models/model_metadata.json          # Training metadata and metrics
```

These files are generated by running:

```bash
python -m src.models.train
```

locally and must be committed to Git so Streamlit Cloud can load them at startup.

## Git Configuration

The `.gitignore` file has been configured to **allow** these essential runtime files:

```
✅ data/raw/HR-Employee-Attrition.csv
✅ models/attrition_model.pkl
✅ models/preprocessor.pkl
✅ models/model_metadata.json
```

While excluding unnecessary or large artefacts:

```
❌ __pycache__/
❌ .venv/
❌ data/processed/ (intermediate files)
❌ .env (secrets)
```

## Python Version

`runtime.txt` pins the deployment Python version to **3.11**, avoiding compatibility issues with cutting-edge Python versions (e.g., 3.14). Streamlit Cloud will use this version for all deployments of this app.

## Before deploying to Streamlit Cloud

Ensure these files are tracked and committed:

```bash
git add data/raw/HR-Employee-Attrition.csv
git add models/attrition_model.pkl
git add models/preprocessor.pkl
git add models/model_metadata.json
git add runtime.txt
git add .gitignore
git add DEPLOYMENT.md

git commit -m "Configure deployment with required data and model artifacts"
git push
```

## Path Resolution

All paths are resolved from the project root using `src/config.py`:

```python
ROOT_DIR = Path(__file__).resolve().parent.parent

DATA_RAW_DIR = ROOT_DIR / "data" / "raw"
MODELS_DIR = ROOT_DIR / "models"
RAW_DATA_PATH = DATA_RAW_DIR / "HR-Employee-Attrition.csv"
MODEL_PATH = MODELS_DIR / "attrition_model.pkl"
```

This ensures paths work correctly regardless of whether Streamlit starts from the repository root or a subdirectory.

## Troubleshooting

If Streamlit Cloud shows `FileNotFoundError`:

1. Verify the file exists in your GitHub repository (not just locally).
2. Check that `data/raw/HR-Employee-Attrition.csv` appears in the GitHub web interface.
3. Confirm `models/*.pkl` and `models/model_metadata.json` are also pushed.
4. Redeploy the Streamlit app after pushing changes.

If you see Python compatibility errors on Streamlit Cloud, confirm that `runtime.txt` contains `python-3.11`.
